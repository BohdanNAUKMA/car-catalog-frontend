# AutoHub — Frontend

Мінімальний веб-інтерфейс каталогу автомобілів. Сторінка робить `fetch`-запит до REST API бекенду та відображає список автомобілів у вигляді карток (з пошуком за моделлю, фільтром за типом палива та сортуванням).

## Адреси

| Компонент | Адреса |
|-----------|--------|
| Frontend  | http://127.0.0.1:5500 (або http://localhost:5500) |
| Backend API | http://127.0.0.1:8000/api/v1/ |
| Ендпоінт, який використовує сторінка | http://127.0.0.1:8000/api/v1/cars/ |

> Бекенд дозволяє CORS-запити лише з `http://localhost:5500` та `http://127.0.0.1:5500`, тому фронтенд потрібно запускати саме на порті **5500**.

## Структура

```
frontend_repo/
├── index.html   # розмітка сторінки
├── style.css    # стилі
└── app.js       # завантаження та рендеринг автомобілів
```

## Як запустити

1. Запустіть бекенд (інструкція — у кореневому `README.md`) і переконайтеся, що він доступний за адресою http://127.0.0.1:8000/api/v1/cars/.

2. Запустіть фронтенд одним зі способів:

   **Варіант A — VS Code Live Server**

   - Встановіть розширення **Live Server** (Ritwick Dey).
   - Відкрийте папку `frontend_repo` у VS Code.
   - Натисніть правою кнопкою на `index.html` → **Open with Live Server** (порт за замовчуванням — `5500`).

   **Варіант B — вбудований сервер Python**

   ```bash
   cd frontend_repo
   python -m http.server 5500
   ```

3. Відкрийте у браузері http://127.0.0.1:5500.

## Можливі проблеми

- **«Не вдалося підключитися до сервера»** — бекенд не запущено або він працює не на порті `8000`.
- **CORS-помилка в консолі браузера** — фронтенд відкрито не з порту `5500` або напряму як файл (`file://`).
