# AutoHub — Frontend

Клієнтський веб-додаток каталогу автомобілів (Vanilla JS + HTML + CSS) із підтримкою JWT-автентифікації, розмежуванням прав доступу та автоматичним оновленням токенів (Silent Refresh).

## Адреси

| Компонент | Адреса |
|-----------|--------|
| Frontend  | http://127.0.0.1:5500 (або http://localhost:5500) |
| Backend API | http://127.0.0.1:8000/api/v1/ |

> Бекенд дозволяє CORS-запити лише з `http://localhost:5500` та `http://127.0.0.1:5500`, тому фронтенд потрібно запускати саме на порті **5500**.

## Структура та сторінки

```
frontend_repo/
├── index.html      # головна сторінка каталогу (доступна всім)
├── login.html      # сторінка входу
├── register.html   # сторінка реєстрації з валідацією полів
├── add-car.html    # захищена сторінка додавання автомобіля
├── style.css       # спільні стилі
├── api.js          # обгортка apiFetch із Silent Refresh та робота з localStorage
├── auth.js         # рендеринг шапки, Logout та route guards (?next=...)
├── forms.js        # зчитування форм і відображення помилок полів
├── app.js          # логіка каталогу та захищене видалення авто
├── login.js        # логіка форми входу
├── register.js     # клієнтська та серверна валідація реєстрації
└── add-car.js      # логіка захищеної форми створення авто
```

### Функціонал сторінок і стану авторизації

1. **Стан у `localStorage`:**
   - Токени та профіль зберігаються за ключами `autohub.accessToken`, `autohub.refreshToken` і `autohub.user`.
2. **Шапка сайту (`auth.js`):**
   - Для **гостя** відображаються кнопки **«Увійти»** та **«Зареєструватися»**.
   - Для **авторизованого користувача** відображається його `username` та кнопка **«Вийти»** (Logout), яка очищує `localStorage` і повертає на головну сторінку.
3. **Захищені сторінки та дії:**
   - **Форма додавання авто (`add-car.html`)** доступна лише авторизованим користувачам. Якщо гість відкриває `add-car.html`, виконується редирект на `login.html?next=add-car.html`, а після успішного входу або реєстрації користувач автоматично повертається на `add-car.html`.
   - **Кнопка «Видалити»** на картці авто в каталозі відображається лише авторизованим користувачам і надсилає `DELETE /api/v1/cars/<id>/` із заголовком `Authorization: Bearer <access_token>`.
   - Якщо залогінений користувач відкриває `login.html` або `register.html`, його автоматично перенаправляє на каталог (`index.html` або адресу з `?next=...`).

## Як працює автоматичне оновлення токена (Silent Refresh)

Усі запити до API виконуються через функцію `apiFetch(path, options)` у модулі `api.js`:

1. Якщо для запиту передано `{ auth: true }`, до заголовків додається `Authorization: Bearer <access_token>`.
2. Якщо сервер повертає `401 Unauthorized` (наприклад, сплив термін дії `access`-токена), `apiFetch` автоматично виконує фоновий запит `POST /api/v1/auth/token/refresh/` із збереженим `refresh`-токеном.
3. Одночасні запити використовують спільний проміс `refreshInFlight`, щоб не дублювати запити на оновлення токена.
4. Якщо оновлення успішне — новий `access`-токен зберігається в `localStorage`, а початковий запит прозоро повторюється без повторного входу користувача.
5. Якщо `refresh`-токен також недійсний або прострочений — `localStorage` очищується, і користувач перенаправляється на `login.html?next=<поточна_сторінка>`.

## Як запустити

1. Запустіть бекенд (інструкція — у кореневому `README.md`) і переконайтеся, що він працює на http://127.0.0.1:8000.

2. Запустіть фронтенд одним зі способів:

   **Варіант A — VS Code Live Server**

   - Встановіть розширення **Live Server** (Ritwick Dey).
   - Відкрийте папку `frontend_repo` у VS Code.
   - Натисніть правою кнопкою на `index.html` → **Open with Live Server** (порт за замовчуванням — `5500`).

   **Варіант B — вбудований сервер Python**

   ```bash
   cd frontend_repo
   python -m http.server 5500
   ```

3. Відкрийте у браузері http://127.0.0.1:5500.

## Можливі проблеми

- **«Не вдалося підключитися до сервера»** — бекенд не запущено або він працює не на порті `8000`.
- **CORS-помилка або помилка ES-модулів** — фронтенд відкрито не з порту `5500` або напряму як локальний файл (`file://`).
